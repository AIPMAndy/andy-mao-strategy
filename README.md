## 🚀 核心特性

### 第一性原理融合

**毛泽东的第一性原理 = Andy 的认知公理在战略领域的具体化**

| Andy 认知公理 | 毛泽东对应方法 | 
|-------------|--------------|
| 熵增定律 | 持久战三阶段 — 无永久解决方案，需持续能量输入 |
| 还原论 | 矛盾分析法 — 拆解到不可再分的矛盾单元 |
| 对立统一 | 矛盾论核心 — 矛盾双方互为存在条件 |
| 演化选择 | 实事求是 + 调查研究 — 试错-选择-留存 |
| 有限理性 | 主要矛盾识别 — 追求满意解而非最优解 |
| 机会成本 | 集中兵力打歼灭战 — 考虑边际成本收益 |
| 系统涌现 | 群众路线 — 自下而上的自组织 |

### 与 Musk 五步法协同

**Musk 五步法是"删除优先"，毛泽东方法论提供"删除的判断依据"**

1. **质疑需求** ↔ 实事求是核查表
2. **删除部分** ↔ 主要矛盾识别（删除次要矛盾）
3. **简化优化** ↔ 集中兵力打歼灭战
4. **加速周期** ↔ 非对称竞争十六字诀
5. **自动化** ↔ 群众路线（自组织涌现）

### 使命锚点集成

每个战略决策都必须回答：**这如何推进让 80 亿人通过 AI 获得自由的使命？**

| 使命维度 | 方法论应用 |
|---------|-----------|
| 多行星文明备份 | 星星之火评估法 |
| 全链可持续能源 | 农村包围城市 |
| 人机共生平衡 AGI | 对立统一 |
| AI 赋能 80 亿人 | 群众路线 |

## 📊 6 大应用场景

### 🔴 技术战略决策
判断技术方向、投资决策、市场时机
- 星星之火评估法 → "有没有戏"
- 矛盾转化法 → 找拐点
- 持久战三阶段 → 判断阶段
- 农村包围城市 → 边缘突破

### 🟠 组织团队管理
建立自组织、高效率团队
- 群众路线 → 从群众中来
- 整风诊断 → 识别空谈/山头/形式主义
- 主要矛盾识别 → 找"牛鼻子"
- 调查研究 → 深入一线

### 🟡 弱者竞争战略
用非对称战略对抗强者
- 农村包围城市 → 不争最强，先占最弱
- 集中兵力 → 选一个战场打赢
- 非对称竞争 → 避实击虚
- 矛盾分析 → 找巨头的创新者窘境

### 🔵 长期战略规划
3-10 年路径规划
- 持久战三阶段 → 防御→相持→反攻
- 战略持久战术速决 → 战略耐心 + 战术速度
- 矛盾转化 → 量变质变节点
- 星星之火 → 长期可行性

### 🟢 联盟生态构建
构建生态，推动行业进化
- 统一战线 → 扩大阵营
- 阶级分析 → 利益关系判断
- 又团结又斗争 → 保持独立性
- 有理有利有节 → 分寸把握

### ⚫ 危机应对调整
不确定性中的理性决策
- 实事求是核查 → 检查脱离实际
- 调查研究 → 了解真相
- 主要矛盾识别 → 找核心问题
- 矛盾转化 → 判断质变节点

## 📖 3 大决策模板

### 模板 1：技术方向判断（5 分钟）
1. 【还原论】基本矛盾单元是什么？
2. 【星星之火】四维判断（客观条件、主观能动、领导力量、敌方失误）
3. 【矛盾转化】量变质变节点在哪？
4. 【使命对齐】推进了哪个维度？
5. 【决策】投入/观望/放弃 + 置信度

### 模板 2：资源分配决策（Musk × 毛泽东）
1. 【质疑需求 × 实事求是】真的必要吗？
2. 【删除部分 × 主要矛盾】删除次要矛盾
3. 【简化优化 × 集中兵力】资源如何聚焦？
4. 【加速周期 × 非对称竞争】如何快速迭代？
5. 【自动化 × 群众路线】如何自组织？

### 模板 3：团队问题诊断（整风版）
1. 【主观主义】决策脱离实际？
2. 【宗派主义】山头林立？
3. 【党八股】形式主义？
4. 【群众路线】如何修复？
5. 【行动方案】删除什么、建立什么？

## 🎯 数据诚信原则

### 绝对禁止

| ❌ 错误表述 | ✅ 正确表述 |
|-----------|-----------|
| "我们能赢" | "基于 XX 数据，在 XX 条件下，置信度 XX%" |
| "市场前景广阔" | "TAM XX 亿，3 年可获取 XX%，置信度 XX%" |
| "这个方向一定会火" | "基于 XX 指标，处于 XX 阶段，质变节点预计 XX" |

### 核心原则
- 不美化竞争形势
- 不模糊判断
- 不混淆相关与因果
- 不确定时说"置信度 XX%"
